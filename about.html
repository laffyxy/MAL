About MalTranslate

Malayalam OCR & English translation, in your browser

MalTranslate reads Malayalam text from a photo or image and translates it into clear, natural English. Snap a sign, a page from a book, a menu or a handwritten note, and get both the Malayalam text and its English meaning in seconds.

How it works

  • Capture: upload an image, drag one in, or take a photo with your camera.
  • Extract: the image is sent to Google's Gemini model, which reads the Malayalam text while keeping its layout.
  • Translate: Gemini then produces a context-aware English translation.
  • Keep: your 15 most recent results are saved in your browser so you can come back to them.

Bring your own key

MalTranslate has no servers and no accounts. It talks to the Gemini API directly from your browser using your own free API key from Google AI Studio. Your key stays on your device. See the Privacy Policy for details.

Install it

MalTranslate is a Progressive Web App. Add it to your home screen on Android or iOS, or install it from the address bar on desktop, and it will open like a native app, even with a spotty connection (translation itself needs internet).

Open source

MalTranslate is built with plain HTML, CSS and JavaScript. The source code is on GitHub under the MIT License.

Reporting bugs

Bug reports are accepted only through GitHub Issues. Reports sent any other way may not be seen. Before opening a new issue, please check whether it has already been reported.

A helpful report includes:

  • what you did and what you expected to happen;
  • what actually happened, including any error message shown;
  • your device, browser and the Gemini model you selected.

Please never include your API key in an issue, and don't attach images that contain private information. Issues are public. Security vulnerabilities should be reported privately instead. See the security policy.
